## Features

- **Interactive Visualizations** — Set operations, measure construction, Lebesgue integral approximation, convergence mode comparisons, Lp space geometry, product measures, Fourier transforms
- **Rigorous Theory with Geometric Intuition** — Every abstract definition is grounded in visual examples before formalization
- **Computational Focus** — Learn to compute measures, integrals, and Lp norms through interactive examples
- **Classic and Modern** — From Caratheodory extension to Haar measure and probability
- **Bilingual Presentation** — Chapter titles in Chinese and English; mathematical exposition accessible to both audiences
